# Lumen Store, site vitrine de démonstration

Site vitrine d’une boutique d’accessoires à Dakar. Les clients choisissent un article et envoient leur commande par WhatsApp, avec un message déjà rédigé.

**Voir le site :** [ajoute ici le lien de ton site en ligne]

> Projet de démonstration : les produits, les prix et les avis sont fictifs.

## Fonctionnalités

- Page d’accueil avec boutons WhatsApp
- Boutique de 6 produits, avec prix en FCFA
- Bouton « Commander » qui ouvre WhatsApp avec le message prérempli
- Avis clients, étapes de commande, horaires et zone de livraison
- Affichage adapté au téléphone, avec mode sombre automatique

## Technologies

- HTML et CSS
- JavaScript (sans bibliothèque)
- Un seul fichier : `index.html`

## Personnaliser le site

Ouvre `index.html` et cherche le bloc `<script>` en bas du fichier :

- `BOUTIQUE` : le nom de la boutique et le numéro WhatsApp (format international, sans le `+`, par exemple `221770000000`)
- `PRODUITS` : la liste des articles (nom, description, prix, emoji et couleur)

Les textes (titre, horaires, avis, Instagram) se modifient directement dans le HTML.

## Lancer le site en local

Aucune installation n’est nécessaire : double-clique sur `index.html` pour l’ouvrir dans ton navigateur.

## Mettre en ligne

Le site est statique, il peut être hébergé gratuitement sur Netlify, GitHub Pages ou Cloudflare Pages.
